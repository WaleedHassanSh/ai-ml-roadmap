# AI/ML Learning Roadmap

This repository documents my complete computer science, artificial intelligence, and machine learning learning journey.

It is intentionally a **learning repository**, so it contains course work, exercises, notes, notebooks, experiments, mini-projects, and larger projects from different phases of the roadmap.

For selected phases, I will also choose one strong project and maintain it separately as a polished standalone GitHub repository.

## Project Strategy

This repository stores the **complete learning history**.

Not every exercise or mini-project here is intended to be a standalone portfolio project.

For each major phase, I may select one strong project and create a separate repository for it with:

- a focused README
- installation and usage instructions
- tests
- clear project structure
- results or evaluation
- screenshots or demos when relevant
- technical decisions and limitations

This allows this repository to remain a complete learning archive while the strongest projects are presented separately as portfolio-quality work.
