# Terminal Cheat Sheet

## Navigation

- pwd
- ls
- cd folder_name
- cd ..
- mkdir new_folder

## Files

- touch file.txt
- cp source.txt dest.txt
- mv old.txt new.txt
- rm file.txt

## Pipes and redirection

- command > file.txt
- command >> file.txt
- command1 | command2

## Git

- git init
- git status
- git add .
- git commit -m "message"
- git push
- git pull
- git clone <repo-url>
