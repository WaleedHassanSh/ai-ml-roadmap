# Phase 1: Python From Zero

This folder contains my Phase 1 Python work from my AI/ML roadmap.

## Purpose

The purpose of this phase is to become comfortable writing small Python programs independently.

This phase focuses on:

- Inputs and outputs
- Variables, types, and expressions
- Conditionals and loops
- Functions and scope
- Exceptions and debugging
- Libraries and packages
- File I/O
- Regular expressions
- OOP basics
- Basic tests
