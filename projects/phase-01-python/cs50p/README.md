# CS50P Practice

This folder contains my practice work for CS50's Introduction to Programming with Python as part of Phase 1 of my AI/ML roadmap.

## Purpose

The purpose of this folder is to organize my CS50P exercises and final project by week.

CS50P helps me build a strong Python foundation before moving into data analysis, machine learning, deep learning, and AI systems.

## Course Focus

This folder covers Python fundamentals including:

- Functions and variables
- Conditionals
- Loops
- Exceptions
- Libraries
- Unit tests
- File I/O
- Regular expressions
- Object-oriented programming
- Final project development
