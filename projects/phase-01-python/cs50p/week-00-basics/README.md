# CS50P Week 00 Basics

This folder contains my solutions for beginner-level exercises from **CS50’s Introduction to Programming with Python**.

## Purpose

These exercises are part of my **Phase 01: Python** foundation in my AI/ML roadmap.  
The goal is to strengthen basic Python programming skills before moving to more advanced topics.

## Exercises Included

### 1. Indoor Voice

**Folder:** `indoor/`  
**File:** `indoor.py`

Converts user input to lowercase.

### 2. Playback Speed

**Folder:** `playback/`  
**File:** `playback.py`

Replaces spaces in user input with `...`.

### 3. Making Faces

**Folder:** `faces/`  
**File:** `faces.py`

Converts emoticons like `:)` and `:(` into emoji.

### 4. Einstein

**Folder:** `einstein/`  
**File:** `einstein.py`

Calculates energy using Einstein’s formula:

E = m \* c^2

where:

- `m` = mass
- `c` = speed of light (`300000000`)

### 5. Tip Calculator

**Folder:** `tip/`  
**File:** `tip.py`

Calculates the tip amount based on meal cost and tip percentage.

## Skills Practiced

- taking input with `input()`
- printing output with `print()`
- string methods like `.lower()` and `.replace()`
- writing functions
- basic arithmetic
- using `int()` and `float()`
- simple program structure in Python

## Why This Matters

These small exercises build the base for:

- writing clean Python code
- understanding input/output flow
- working with strings and numbers
- preparing for later AI/ML coding tasks

## How to Run

Open a terminal in the relevant folder and run:

```bash
python filename.py
```
