# CS50P Week 01 Conditionals

This folder contains my solutions for condition-based exercises from **CS50’s Introduction to Programming with Python**.

## Purpose

These exercises are part of my **Phase 01: Python** foundation in my AI/ML roadmap.  
The goal is to strengthen decision-making logic in Python using conditional statements before moving to more advanced programming concepts.

## Exercises Included

### 1. Deep Thought

**Folder:** `deep/`  
**File:** `deep.py`

Checks whether the user’s input matches the answer to the Great Question of Life, the Universe, and Everything.

### 2. Home Federal Savings Bank

**Folder:** `bank/`  
**File:** `bank.py`

Classifies a greeting and outputs the corresponding dollar amount based on how the greeting starts.

### 3. File Extensions

**Folder:** `extensions/`  
**File:** `extensions.py`

Determines a file’s media type based on its extension.

### 4. Math Interpreter

**Folder:** `interpreter/`  
**File:** `interpreter.py`

Takes a simple arithmetic expression from the user and evaluates it.

### 5. Meal Time

**Folder:** `meal/`  
**File:** `meal.py`

Converts a given time into hours and checks whether it is breakfast, lunch, or dinner time.

## Skills Practiced

- using `if`, `elif`, and `else`
- comparing strings and values
- string methods like `.strip()`, `.lower()`, `.startswith()`, and `.endswith()`
- splitting input with `.split()`
- basic arithmetic operations
- writing and calling functions
- formatting output correctly

## Why This Matters

These exercises build the base for:

- making decisions in Python programs
- handling different user inputs correctly
- writing more logical and structured code
- preparing for later problem-solving and AI/ML coding tasks
