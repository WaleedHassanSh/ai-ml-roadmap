# CS50P Week 02 Loops

This folder contains my solutions for loop-based and input-processing exercises from **CS50’s Introduction to Programming with Python**.

## Purpose

These exercises are part of my **Phase 01: Python** foundation in my AI/ML roadmap.  
The goal is to strengthen repetition, iteration, validation, and string-processing skills in Python before moving to more advanced programming concepts.

## Exercises Included

### 1. camelCase

**Folder:** `camel/`  
**File:** `camel.py`

Converts a variable name from camel case into snake case.

### 2. Coke Machine

**Folder:** `coke/`  
**File:** `coke.py`

Simulates a Coke vending machine that accepts only specific coin denominations and calculates the remaining amount due or change owed.

### 3. twttr

**Folder:** `twttr/`  
**File:** `twttr.py`

Removes vowels from a string of text, similar to how words are shortened in texting.

### 4. Vanity Plates

**Folder:** `plates/`  
**File:** `plates.py`

Validates whether a license plate follows a given set of formatting rules.

### 5. Nutrition Facts

**Folder:** `nutrition/`  
**File:** `nutrition.py`

Looks up the calorie count of a fruit using a dictionary of nutrition data.

## Skills Practiced

- using `for` and `while` loops
- iterating through strings character by character
- validating user input
- working with conditions inside loops
- using string methods like `.lower()`, `.isalpha()`, `.isdigit()`, and `.isalnum()`
- using dictionaries for lookup
- formatting output correctly
- building logic step by step for small real-world problems

## Why This Matters

These exercises build the base for:

- processing input repeatedly until conditions are met
- solving problems by scanning data one element at a time
- writing cleaner validation logic
- improving confidence with Python control flow
- preparing for later problem-solving, automation, and AI/ML coding tasks

## How to Run

Open a terminal in the relevant folder and run:

```bash
python filename.py
```
