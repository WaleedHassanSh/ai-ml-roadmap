# CS50P Week 03 Exceptions

This folder contains my solutions for exception-handling and input-validation exercises from **CS50’s Introduction to Programming with Python**.

## Purpose

These exercises are part of my **Phase 01: Python** foundation in my AI/ML roadmap.  
The goal is to strengthen exception handling, robust input processing, validation, and dictionary-based problem solving in Python before moving to more advanced programming concepts.

## Exercises Included

### 1. Fuel Gauge

**Folder:** `fuel/`  
**File:** `fuel.py`

Prompts the user for a fraction and converts it into a fuel percentage, displaying `E`, `F`, or the rounded percentage depending on the amount of fuel.

### 2. Felipe’s Taqueria

**Folder:** `taqueria/`  
**File:** `taqueria.py`

Simulates a simple ordering system that keeps a running total based on menu items entered by the user until input ends.

### 3. Grocery List

**Folder:** `grocery/`  
**File:** `grocery.py`

Builds and prints a sorted grocery list in uppercase, showing how many times each item was entered.

### 4. Outdated

**Folder:** `outdated/`  
**File:** `outdated.py`

Converts dates from multiple user-input formats into standard `YYYY-MM-DD` format after validating the input.

## Skills Practiced

- using `try` and `except` for error handling
- handling `ValueError`, `ZeroDivisionError`, and `EOFError`
- validating and re-prompting user input
- parsing strings with `.split()` and `.replace()`
- working with dictionaries for lookup and counting
- formatting numeric and string output correctly
- building more fault-tolerant Python programs

## Why This Matters

These exercises build the base for:

- writing programs that do not crash on invalid input
- making user-driven programs more reliable
- handling edge cases carefully
- improving confidence with exception handling and validation
- preparing for later problem-solving, scripting, automation, and AI/ML coding tasks

## How to Run

Open a terminal in the relevant folder and run:

```bash
python filename.py
```
