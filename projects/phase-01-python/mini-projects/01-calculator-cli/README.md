# Calculator CLI

A command-line calculator that performs basic arithmetic operations with input validation.

## Purpose

This project practices basic Python program structure using inputs, outputs, functions, conditionals, loops, and exception handling.

## Features

- Show a calculator menu
- Add two numbers
- Subtract two numbers
- Multiply two numbers
- Divide two numbers
- Handle invalid menu choices
- Handle invalid number input
- Handle division by zero
- Keep running until the user exits

## Concepts Practiced

- Variables
- Types
- Expressions
- Input/output
- Conditionals
- Loops
- Functions
- Exceptions and debugging

## Main File

```text
calculator.py
```

## How to Run

```bash
python calculator.py
```
