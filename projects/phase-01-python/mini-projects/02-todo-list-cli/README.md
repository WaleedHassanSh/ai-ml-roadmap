# To-Do List CLI

A command-line to-do list manager that saves, views, updates, and deletes tasks using a CSV file.

## Purpose

This project practices file-based storage and basic task management using Python.

## Features

- Add a task
- View all tasks
- Mark a task as complete
- Delete a task
- Save tasks to a CSV file
- Load tasks from a CSV file
- Handle invalid menu choices
- Handle empty task titles
- Handle invalid task numbers
- Handle missing or empty task files

## Concepts Practiced

- Input/output
- Functions
- Conditionals
- Loops
- CSV file handling
- Exceptions and debugging
- Basic persistent storage

## Main File

```text
todo_list.py
```

## Data File

```text
tasks.csv
```

## How to Run

```bash
python todo_list.py
```
