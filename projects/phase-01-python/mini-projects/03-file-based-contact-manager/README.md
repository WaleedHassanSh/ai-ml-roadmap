# File-Based Contact Manager

A file-based contact manager that stores, searches, updates, and deletes contacts using a CSV file.

## Purpose

This project practices managing structured records with file storage.

## Features

- Add a contact
- View all contacts
- Search contacts by name
- Update an existing contact
- Delete a contact
- Save contacts to a CSV file
- Load contacts from a CSV file
- Handle invalid menu choices
- Handle empty contact fields
- Handle invalid contact numbers
- Handle missing or empty contact files

## Contact Fields

Each contact contains:

- Name
- Phone number
- Email

## Concepts Practiced

- Input/output
- Functions
- Conditionals
- Loops
- CSV file handling
- Exceptions and debugging
- Basic record management

## Main File

```text
contact_manager.py
```

## Data File

```text
contacts.csv
```

```bash
python contact_manager.py
```
