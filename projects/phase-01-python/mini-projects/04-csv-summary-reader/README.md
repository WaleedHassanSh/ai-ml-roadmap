# CSV Summary Reader

A CSV reader that loads tabular data and prints simple summaries from selected columns.

## Purpose

This project practices reading CSV files and performing simple data summaries.

## Features

- Read a CSV file
- View rows
- Show column names
- Show number of rows
- Count values in a selected column
- Handle invalid menu choices
- Handle missing files
- Handle empty CSV files
- Handle invalid column names
- Prevent actions before loading a file

## Concepts Practiced

- CSV file reading
- Dictionaries
- Lists
- Loops
- Functions
- Input validation
- Exceptions and debugging
- Basic data summarization

```text
csv_summary_reader.py
```

```text
students.csv
```

```bash
python csv_summary_reader.py
```
