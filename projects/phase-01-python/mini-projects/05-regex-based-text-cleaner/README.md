# Regex-Based Text Cleaner

A regex-based text cleaner that cleans messy text and extracts emails and numbers.

## Purpose

This project practices regular expressions and text processing in Python.

## Features

- Enter messy text manually
- Clean extra spaces
- Remove unwanted symbols
- Extract emails
- Extract numbers
- Handle invalid menu choices
- Reject empty text input
- Prevent cleaning before text is entered
- Handle no-email cases
- Handle no-number cases

## Concepts Practiced

- Regular expressions
- Text cleaning
- Pattern matching
- Input/output
- Functions
- Conditionals
- Loops
- Exceptions and debugging

