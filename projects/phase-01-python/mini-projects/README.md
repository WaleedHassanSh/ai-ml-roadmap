# Phase 1 Python Mini Projects

This folder contains my Phase 1 Python mini-projects from my AI/ML roadmap.

## Purpose

The goal of these projects is to practice Python fundamentals by building small command-line programs independently.

These projects focus on:

- Inputs and outputs
- Variables, types, and expressions
- Conditionals and loops
- Functions
- Exceptions and debugging
- File I/O
- CSV handling
- Regular expressions
- Basic program structure

## Projects

### 1. Calculator CLI

A command-line calculator that performs basic arithmetic operations with input validation.
