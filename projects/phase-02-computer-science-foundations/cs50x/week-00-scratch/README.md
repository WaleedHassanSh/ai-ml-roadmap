## Description
This is my CS50x Week 0 Scratch project. It is a simple game where the player controls a robot, catches falling stars to increase the score, and avoids falling beetles to keep lives.

## My Implementation
The project includes:
- A player-controlled robot sprite
- A falling star sprite that increases the score
- A falling beetle sprite that reduces lives
- A score variable
- A lives variable
- A custom falling-speed block
- Game-over logic when lives reach zero

## What I Learned
This project helped me understand how basic programming logic works visually before moving into text-based programming. The same ideas appear later in C, Python, and AI/ML programming:

- Variables store state.
- Loops repeat behavior.
- Conditionals make decisions.
- Events trigger actions.
- Custom blocks help organize repeated logic.
- Abstraction makes projects easier to understand and maintain.
