# Mini Projects

This folder contains small computer science foundation projects created to reinforce concepts from Phase 02.

These projects are smaller than full applications, but each one is designed to strengthen a specific skill such as tracing code, solving problems, using notebooks, or building a simple database application.

## Purpose

The purpose of this folder is to practice computer science concepts through small, focused projects.

These projects help convert theory into practical understanding.

## Folder Structure

```text
mini-projects/
├── 01-cs-foundations-tracing/
├── 02-problem-solving-notebook/
└── 03-student-records-sql-app/
```

## Projects

| Project | Focus |
|---|---|
| `01-cs-foundations-tracing/` | Tracing program execution, understanding control flow, variables, loops, and function behavior. |
| `02-problem-solving-notebook/` | Practicing step-by-step problem solving, explanations, examples, and worked solutions. |
| `03-student-records-sql-app/` | Building a simple SQL-based student records application to practice database operations. |

## Learning Goals

By completing these mini projects, I aim to improve:

- code reading
- manual tracing
- debugging habits
- problem decomposition
- algorithmic thinking
- SQL CRUD operations
- documentation quality
- GitHub project organization

## Recommended Workflow

For each mini project:

1. Read the problem or project goal.
2. Break it into smaller tasks.
3. Write the first working version.
4. Test with simple cases.
5. Fix bugs and edge cases.
6. Add clear notes in the project README.
7. Push the final version to GitHub.

## Why These Projects Matter

These projects are useful because they make foundation concepts practical.

Instead of only watching lectures or reading notes, this folder shows applied work through small exercises and projects.

## Status

This folder is part of Phase 02: Computer Science Foundations. It supports the CS50x work by adding extra practice and project-based reinforcement.
